# Wells Fargo Software Engineering Job Simulation Project
<br>
This repository features two key tasks from the Wells Fargo Software Engineering Virtual Job Simulation on the Forage platform. In this project, I took on the role of a project analyst, focusing on developing a data model to improve how financial advisors manage client portfolios. The two primary tasks involved:

Designing a Data Model and Entity Relationship Diagram (ERD): I created a detailed ERD to align with project requirements and support the development team in structuring a robust relational database. This task highlighted the critical role of ERDs in effective database design.

Implementing the Data Model Using Java: I converted the designed data model into Java classes within Visual Studio Code. This involved defining entities with appropriate annotations like @Entity, ensuring automatic primary key generation, adding constructors for initialization, and implementing getter and setter methods for attributes.
